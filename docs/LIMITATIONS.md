# Ограничения решения

## Поддерживаемые условия

Android 10 и новее, `arm64-v8a`. Форматы: MP3, WAV, M4A, OGG, FLAC. Основной язык русский, английский определяется автоматически.

## Известные ограничения

- GigaAM e2e сама ставит пунктуацию и нормализует текст. Модель может исправлять падежи и заменять редкие слова: настройкой это не отключается, а приложение текст после распознавания не правит.
- Одноканальный ASR даёт один поток слов: при наложении речи каждое слово получает одного говорящего, перекрытие помечается.
- Параметры диаризации получены на английских совещаниях.

## Что не входит в текущую версию

Дообучение моделей, запись с микрофона, редактирование текста, говорящие между сессиями.

## Риски демонстрации

Скорость на стенде проверки неизвестна: образ, число vCPU и хост организаторы не сообщили.

## Дальнейшее развитие

Профили устройств, переименование говорящих, экспорт в Markdown и PDF, регрессионный стенд с эталонными записями.
