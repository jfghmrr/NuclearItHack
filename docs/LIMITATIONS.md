# Ограничения

Условия, в которых работает решение. Числа и условия замеров в [TEST_RESULTS.md](TEST_RESULTS.md).

## Устройство

- Android 10 и новее (`minSdk` 29), архитектура `arm64-v8a`, вычисления на CPU
- Сеть не используется: в приложении нет разрешений `INTERNET` и `ACCESS_NETWORK_STATE`, все модели внутри APK
- APK весит 1,35 ГБ, для установки нужно около 3,2 ГБ свободного места. На чистом эмуляторе по умолчанию свободно 5,0 ГБ
- Свободное место на запись: копия файла до 256 МБ, плюс 34 КБ на секунду звука и резерв 64 МиБ. Файл больше 256 МБ читается на месте. Копия языковой модели занимает 378 МиБ один раз
- Пик памяти: 0,6-0,9 ГБ на русской записи, 1,4 ГБ на английской
- Интерфейс на русском, текст реплик остаётся на языке записи

## Вход

- Форматы: MP3, WAV (включая RF64 и файлы больше 4 ГБ), M4A, OGG, FLAC. Берётся первая звуковая дорожка
- Языки: русский и английский. Язык определяется автоматически один раз на файл, вся запись идёт моделью этого языка. Другие языки с латиницей идут английским маршрутом
- Число говорящих не ограничено
- Длина записи не ограничена: длинные файлы декодируются потоком, диаризация идёт окнами по 5 минут с контрольными точками. Самая длинная запись в наших замерах - 57 минут

## Распознавание и говорящие

- Текст пишет модель распознавания вместе с пунктуацией. После распознавания текст не меняется: ни говорящие, ни протокол слова не правят
- У слов модели есть только начало с шагом 40 мс, конец слова оценивается по длине слова
- Говорящий определяется по отпечатку голоса. Реплике нужна примерно 1,5 с чистой речи, чтобы получить свой отпечаток: совсем короткие ответы относятся к ближайшему говорящему, если перед ними нет смены реплики по тексту и громкости
- Одновременная речь: реплики разных говорящих могут пересекаться по времени, каждое слово относится к одному говорящему
- Редкие англицизмы и архаичная лексика распознаются точнее всего в типичном написании. Результаты на сложной лексике в [TEST_RESULTS.md](TEST_RESULTS.md)

## Скорость

- Время обработки растёт линейно с длиной записи. На телефоне начального уровня (Snapdragon 662) запись на 3 минуты готова за 89 с, на эмуляторе за 36-54 с
- Первый файл после установки ждёт загрузки модели распознавания, следующие начинаются быстрее

## Протокол

- Протокол строит локальная модель Qwen3 0.6B после того, как JSON уже сохранён. Он помечен как черновик: пункты цитируют реплики дословно и ведут к ним по ссылке
- Новый импорт останавливает построение протокола, стенограмма от этого не зависит
