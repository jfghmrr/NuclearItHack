# Безопасность и приватность

## Модель угроз

Запись разговора является конфиденциальной. Приложение не должно передавать её за пределы устройства. Защита строится просто: у приложения нет технической возможности выйти в сеть.

## Меры

| Мера | Как проверить |
|---|---|
| Нет разрешений `INTERNET` и `ACCESS_NETWORK_STATE`: они сняты в манифесте через `tools:node="remove"` | `aapt2 dump permissions app-full-release.apk`, экран проверки в приложении |
| Нет телеметрии и аналитики | Зависимости в `src/mobile/android/gradle/libs.versions.toml` |
| Модели внутри APK, ничего не загружается | Состав `assets/models`, хэши в `config/models.lock` |
| Резервное копирование отключено | `android:allowBackup="false"` в манифесте |
| Диагностика без аудио, текста реплик, имён файлов и путей: имя вырезается и из текста ошибки | Экран проверки, «Скопировать диагностический пакет» |
| Служба языковой модели закрыта для других приложений | `android:exported="false"` у `LlmService` в манифесте |

## Разрешения

Ни одно разрешение не запрашивается при запуске. Файл из системного окна выбора обрабатывается без чтения общей памяти, отказ в уведомлениях обработку не останавливает.

| Разрешение | Зачем |
|---|---|
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_DATA_SYNC`, `FOREGROUND_SERVICE_MEDIA_PROCESSING` | Обработка при выключенном экране |
| `WAKE_LOCK` | Процессор не засыпает во время обработки |
| `POST_NOTIFICATIONS` | Прогресс в уведомлении. Запрашивается только по нажатию |
| `READ_MEDIA_AUDIO`, `READ_EXTERNAL_STORAGE` до API 32 | Список аудио из `Download`, `Music`, `Recordings` и открытие файла по адресу `file://`. Запрашивается только по нажатию |

## Что остаётся на устройстве

Копия исходного файла и промежуточные данные лежат во внутренней папке задачи. Их удаляет удаление записи в истории.

Контрактный JSON публикуется в `Download/Stenokot/` и виден другим приложениям с доступом к общей памяти. Удаление записи его не трогает: файл удаляется только по отдельной отметке с предупреждением.

`metadata.json` содержит версии, хэши, времена и статусы. Текста реплик и звука в нём нет, зато есть SHA-256 исходного файла и контрактного JSON. Хэши показывают, что результат получен из этого файла и этими моделями.
