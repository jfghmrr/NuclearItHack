# Безопасность и приватность

## Модель угроз

Запись разговора является конфиденциальной. Приложение не должно передавать её за пределы устройства.

## Меры

| Мера | Как проверить |
|---|---|
| Нет разрешений `INTERNET` и `ACCESS_NETWORK_STATE` | `aapt2 dump permissions app-full-release.apk` |
| Нет телеметрии и аналитики | Зависимости в `src/mobile/android/gradle/libs.versions.toml` |
| Модели внутри APK | Состав `assets/models`, хэши в `config/models.lock` |
| Резервное копирование отключено | `android:allowBackup="false"` в манифесте |
| Диагностика без аудио и текста реплик | Экран проверки, «Скопировать диагностический пакет» |

## Что остаётся на устройстве

Копия исходного файла и промежуточные данные лежат во внутренней папке задачи. Контрактный JSON публикуется в `Download/Stenokot/` и виден другим приложениям с доступом к общей памяти.
