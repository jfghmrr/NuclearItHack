# Безопасность и приватность

## Модель угроз

Запись разговора конфиденциальна, и приложение не должно передавать её за пределы устройства. Защита простая: у приложения нет технической возможности выйти в сеть.

## Меры

| Мера | Как проверить |
|---|---|
| Нет разрешений `INTERNET` и `ACCESS_NETWORK_STATE`: они сняты в манифесте через `tools:node="remove"` | `aapt2 dump permissions <apk>`. CI отклоняет сборку, если они появились. В приложении: «Настройки», «Приватность и разрешения» |
| Разрешения проверяются по установленному пакету, а не по манифесту из репозитория | Экран «Приватность»: «Проверено по установленному пакету» |
| Нет телеметрии и аналитики | Зависимости в `src/mobile/android/gradle/libs.versions.toml` |
| Модели внутри APK, ничего не загружается | Состав `assets/models`, хэши в `config/models.lock`, кнопка «Проверить файлы моделей» |
| Резервное копирование отключено | `android:allowBackup="false"` в манифесте |
| Диагностика без аудио, текста реплик, имён файлов и путей. Имя файла вырезается и из текста ошибки | «Скопировать диагностику» на экране ошибки или «Диагностика записи» |
| Службы закрыты для других приложений | `android:exported="false"` у `LlmService`, `PipelineService`, `RecordingService` |

## Разрешения

При запуске не запрашивается ни одно разрешение. Файл из системного окна выбора обрабатывается без чтения общей памяти, отказ в уведомлениях обработку не останавливает.

| Разрешение | Зачем |
|---|---|
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_DATA_SYNC`, `FOREGROUND_SERVICE_MEDIA_PROCESSING`, `FOREGROUND_SERVICE_SPECIAL_USE` | Обработка при выключенном экране. Особый тип нужен, когда Android 15 исчерпал шестичасовой лимит обработки |
| `FOREGROUND_SERVICE_MICROPHONE`, `RECORD_AUDIO` | Запись с микрофона. Запрашивается только после нажатия «Записать» |
| `WAKE_LOCK` | Процессор не засыпает во время обработки |
| `POST_NOTIFICATIONS` | Прогресс в уведомлении. Запрашивается только по нажатию |
| `READ_MEDIA_AUDIO`, `READ_EXTERNAL_STORAGE` до API 32 | Список аудио из общих папок и открытие файла по адресу `file://`. Запрашивается только по нажатию |

## Что остаётся на устройстве

Копия исходного файла, `pcm16k.wav` и журналы стадий лежат во внутренней папке задачи. Их удаляет удаление записи. Запись с микрофона удаляется вместе со своей задачей.

Контрактный JSON публикуется в `Download/Stenokot/` и виден другим приложениям с доступом к общей памяти. Удаление записи его не трогает: файл удаляется только по отдельной отметке «Удалить и файл JSON» с предупреждением.

`metadata.json` содержит версии, хэши, времена и статусы. Текста реплик и звука в нём нет, зато есть SHA-256 исходного файла и контрактного JSON. По ним видно, что результат получен из этого файла и этими моделями, а счётчики токенов показывают, что языковая модель действительно работала.
