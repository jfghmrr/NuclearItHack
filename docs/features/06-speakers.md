# Определение говорящих

Диаризация идёт окнами по 5 минут, а книга говорящих сводит кластеры окон к общим номерам на всю запись. Слова привязываются к говорящим уже после этого.

## Как работает

- Окно 5 минут, нахлёст 10 секунд. Короткий хвост присоединяется к последнему окну, в нём мало речи для отпечатка голоса
- Модели: сегментация pyannote и эмбеддинги TitaNet small на двух потоках. Порог кластеризации в окне 0,9, шаг сегментации 0,25, для записей короче 3 минут 0,2
- Отпечаток голоса кластера строится по чистой речи без наложений, от 1,5 до 30 секунд, длинные куски первыми
- Книга говорящих сопоставляет кластер окна с уже известными голосами по косинусу, порог 0,6. Два кластера, звучащие одновременно от 500 мс, не могут стать одним говорящим
- Кластер без отпечатка получает говорящего ближайшей по времени речи
- В конце мелкие говорящие поглощаются ближайшими, порог 2 % всей речи, от 2 до 6 секунд
- Предел 8 говорящих, при частоте источника до 11 025 Гц предел 4. Номера `speaker_N` идут по первому появлению без пропусков
- Журнал `diar.jsonl` пополняется после каждого окна, из него книга собирается заново после перезапуска, результат от прерывания не зависит
- Модели живут только внутри стадии, после неё нативная память освобождена

## Как проверить

Перед началом: запись `dialog1.mp3` с двумя говорящими уже обработана.

1. Откройте запись из «Истории» - реплики подписаны «Говорящий 1» и «Говорящий 2». Сверьте смену говорящего со сменой голоса на слух
2. Импортируйте `long.mp3` и дождитесь этапа «Определение говорящих» - счётчик окон растёт, запись длиннее 5 минут даёт несколько окон
3. Откройте результат и сравните начало и конец записи - один человек должен носить один номер

## Ограничения

- Параметры получены на английских совещаниях, на русских записях не откалиброваны
- DER не измерен
- Говорящий с очень малой долей речи может быть поглощён
- Говорящие между разными записями не узнаются
- Наложенная речь не разделяется, см. [07. Слияние слов и говорящих](07-merge.md)
