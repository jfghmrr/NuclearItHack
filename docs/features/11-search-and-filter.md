# Поиск и фильтр

В длинной стенограмме нужное находится поиском по тексту и фильтром по говорящему. Обе функции меняют только показ, файл JSON остаётся прежним.

## Как работает

- Поиск «Найти в стенограмме» идёт по тексту реплик на устройстве. Регистр и разница между е и ё не учитываются. В списке остаются реплики с совпадениями, найденное выделено жирным, поэтому видно и без цвета. Порядок реплик не меняется
- Найденное показано счётчиком «{i} из {n}», стрелки переходят к предыдущему и следующему совпадению. Если ничего нет: «Ничего не найдено» и «Показать все реплики»
- «Говорящие · N» открывает лист «Говорящие»: «Все говорящие» и каждый участник с числом его реплик. «Применить» оставляет реплики выбранного, рядом с числом реплик видно «{x} из {y}»
- Поиск и фильтр работают вместе
- Клавиатура не закрывает поле поиска: окно учитывает её высоту
- Из найденной реплики работает всё то же: нажатие запускает звук с её начала
- Ни поиск, ни фильтр не трогают `Download/Stenokot/<имя>.json`

## Как проверить

Перед началом: запись `dialog1.mp3` открыта на вкладке «Стенограмма».

1. Нажмите значок поиска и введите слово из текста - остаются реплики с этим словом, совпадения выделены, виден счётчик
2. Нажмите стрелку «следующее» - список переходит к следующему совпадению
3. Очистите поле - возвращается вся стенограмма
4. Нажмите «Говорящие · 2», выберите «Говорящий 1» и «Применить» - остаются только его реплики
5. Введите слово при выбранном говорящем - остаются реплики этого говорящего с этим словом
6. Выполните `shasum -a 256` для файла JSON - хэш тот же, что до поиска

## Ограничения

- Поиск сравнивает текст, а не смысл: другая форма слова может не найтись
- Поиск идёт по тому, что выдала модель, ошибка распознавания скрывает слово от поиска
