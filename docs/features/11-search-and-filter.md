# Поиск и фильтр

В длинной стенограмме нужное находится поиском по тексту и фильтром по говорящему. Обе функции меняют только показ, контрактный файл остаётся прежним.

## Как работает

- Поиск идёт по тексту реплик на устройстве
- Фильтр оставляет реплики выбранного говорящего. Говорящие подписаны номером и формой, цвет только дополняет их
- Поиск и фильтр работают вместе
- Клавиатура не закрывает поле поиска: окно учитывает её высоту
- Из найденной реплики работает всё то же: нажатие запускает звук с её начала
- Ни поиск, ни фильтр не трогают `Download/Stenokot/<имя>.json`

## Как проверить

Перед началом: запись `dialog1.mp3` открыта на вкладке «Стенограмма».

1. Введите слово из текста - в списке только реплики с этим словом
2. Очистите поле - возвращается вся стенограмма
3. Выберите одного говорящего - остаются только его реплики
4. Введите слово при выбранном говорящем - остаются реплики этого говорящего с этим словом
5. Нажмите найденную реплику - запись играет с её начала
6. Выполните `shasum -a 256` для файла JSON - хэш тот же, что до поиска

## Ограничения

- Поиск сравнивает текст, а не смысл: другая форма слова может не найтись
- Поиск идёт по тому, что выдала модель, ошибка распознавания скрывает слово от поиска
