# Файл JSON

Результат сохраняется автоматически, без диалогов и разрешений, и строго по контракту задания. В файле один объект и ничего служебного.

## Как работает

```json
{"transcript":[{"speaker_id":"speaker_1","start_ms":1250,"end_ms":4380,"text":"Добрый день!"}]}
```

- Файл: `Download/Stenokot/<имя>.json`. Служебные данные и протокол лежат отдельно в `Download/Stenokot/meta/`
- Файл записывается до старта языковой модели и от неё не зависит
- Проверяются именно те байты, что будут записаны:
  1. UTF-8 без BOM, корень - объект ровно с ключом `transcript`
  2. `transcript` - массив, пустой допустим
  3. В записи ровно ключи `speaker_id`, `start_ms`, `end_ms`, `text`
  4. Типы: строка, целое без дробной части и экспоненты
  5. `0 <= start_ms < end_ms <= длительность + 50 мс`
  6. Сортировка по `start_ms`, пересечения разрешены
  7. `speaker_id` вида `speaker_N`, нумерация сплошная по первому появлению
  8. `text` непустой, без управляющих символов
  9. Повторный разбор даёт равный объект
- При провале проверки файл не появляется нигде, код `CONTRACT_INVALID`
- Файл публикуется целиком через системное хранилище, разрешений для этого не нужно. Пока запись идёт, файла в папке не видно
- Повторная обработка того же файла заменяет свой результат, а не создаёт `<имя> (1).json`. Другой файл с тем же именем получает имя с расширением: `a.mp3` даёт `a.json`, затем `a.wav` даёт `a.wav.json`
- Если запись в `Download` не удалась, тот же файл сохраняется в `Android/data/ru.stenokot.app/files/export/`, а на экране виден настоящий путь
- Статус `DONE` появляется последним, когда в `meta/` уже лежат протокол и `metadata.json`. Если их сохранить не удалось, статус `DONE_META_FAILED`, а JSON не трогается

## Как проверить

Перед началом: Главная, `dialog1.mp3` в `Download`.

1. Импортируйте `dialog1.mp3` и дождитесь `TRANSCRIPT_READY` - `adb shell ls /sdcard/Download/Stenokot/` показывает `dialog1.json` и папку `meta`
2. Заберите файл и проверьте ключи:

```sh
adb pull /sdcard/Download/Stenokot/dialog1.json
python3 -c "import json;d=json.load(open('dialog1.json',encoding='utf-8'));print(set(d),{tuple(sorted(i)) for i in d['transcript']})"
```

Ожидается `{'transcript'} {('end_ms', 'speaker_id', 'start_ms', 'text')}`.

3. Выполните `shasum -a 256 dialog1.json` до и после конца протокола - хэш не меняется и совпадает с хэшем в сведениях о файле результата
4. Импортируйте `silence.wav` - `silence.json` содержит `{"transcript":[]}`, `txt_status` показывает `DONE`
5. Выполните `./gradlew :core:test --tests 'ru.stenokot.core.contract.*'` в `src/mobile/android` - тесты проходят, пример из задания принимается

## Ограничения

- Файл виден другим приложениям с доступом к общей памяти
- Файл, оставшийся от удалённой установки, заменить нельзя: новый результат получает имя `<имя> (1).json`
- Перекрытие, язык и предупреждения в контракт не входят: они есть только в `meta/`
