# Распознавание речи

Запись режется на срезы, язык определяется по трём пробным срезам, текст даёт модель со встроенной пунктуацией. После модели текст никто не правит.

## Как работает

- Декодирование: `MediaExtractor`, `MediaCodec`, сведение в моно, 16 кГц, потоковая запись в `pcm16k.wav`. Длительность считается по числу отсчётов
- Громкость приводится к -23 дБFS только в момент чтения: файл и шкала времени не меняются
- Silero VAD считает вероятность речи окнами по 512 отсчётов. Он нужен только для разрезов и пропуска пауз от 2 секунд при вероятности ниже 0,2. Пауза короче остаётся в срезе вместе с мычанием
- Цель среза 15-20 секунд, жёсткий предел 22 секунды, запас по краям 0,2 секунды
- Сплошная речь режется в точке наименьшей вероятности. Если провала нет, срезы идут внахлёст на 2 секунды
- Язык определяется голосованием служебных слов в трёх срезах из разных мест записи. Английский выбирается только при уверенном перевесе, иначе остаётся русский. Решение одно на файл
- Русский маршрут: GigaAM v3 e2e RNNT. Английский маршрут: Parakeet TDT 110M. Оба работают на CPU, поиск жадный
- Потоки: `max(2, min(4, производительные ядра, ядра - 1))`
- Пунктуация, регистр и междометия приходят из модели, которая слышит звук. Языковая модель к этому тексту не прикасается
- Журнал `asr.jsonl` пополняется после каждого среза. Срез получает две попытки, затем пропускается с отметкой в `metadata.json`
- Сбой определения языка не смертелен: запись идёт русским маршрутом с предупреждением `LANG_ID_FAILED`

## Как проверить

Перед началом: Главная, задач в работе нет.

1. Импортируйте `dialog1.mp3` и дождитесь результата - текст с пунктуацией и заглавными буквами, в том виде, в каком его выдала модель
2. Выполните `adb pull /sdcard/Download/Stenokot/meta/dialog1.metadata.json` - поле `language` равно `RU`, в `lang_votes` голоса служебных слов, в `models` хэши, в `threads` число потоков
3. Импортируйте `english.mp3` - результат подписан «Язык определён автоматически: английский», текст реплик на английском, поле `language` равно `EN`

## Ограничения

- GigaAM e2e может исправлять падежи и заменять редкие слова. Настройкой это не отключается
- Модель со знаками уступает варианту без знаков в чистом WER, цена на наших записях не измерена. Подробно в [LIMITATIONS.md](../LIMITATIONS.md)
- Пороги определения языка не откалиброваны, смешанная запись идёт одной моделью
- Silero VAD может пропускать высокие голоса и принимать инструменты за речь
- WER не измерен
