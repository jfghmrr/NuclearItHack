# Очередь и история

Одновременно работает одна тяжёлая задача, остальные ждут в порядке поступления. Готовые записи остаются в истории и открываются без повторной обработки.

## Как работает

- Порядок строго по поступлению. Файл копируется сразу, поэтому ждать очереди можно сколько угодно
- Статусы: «Готово», «Обрабатывается», «Ожидает», «Приостановлено», «Ошибка», «Результат сохранён». Отменённая запись показывается как «Отменено»
- Статус всегда написан словом и с значком, цвет только дополняет их. Отмена не красится красным
- Главная раскладывает записи по смыслу: карточка работающей задачи, «Очередь», карточка прерванной задачи, «Найденные аудио», «История»
- На карточке работающей задачи видно «В очереди: {файлов}»
- Новый файл во время тяжёлых стадий встаёт в очередь. Если идёт только языковая модель, она останавливается меньше чем за 1 с, потому что новая работа важнее протокола
- В истории рядом со статусом стоит состояние протокола: «Протокол готов», «Протокол частичный», «Протокол отложен», «Протокол пропущен», «Протокол не создан», «Речи не найдено»
- Удаление требует подтверждения: «Удалить запись?», «Запись и её стенограмма исчезнут из приложения. Файл JSON в папке Download/Stenokot останется на месте»
- Файл JSON удаляется только по отдельной отметке «Удалить и файл JSON». При этом видно предупреждение «Файл JSON будет удалён с устройства, вернуть его нельзя»

## Как проверить

Перед началом: Главная, задач в работе нет.

1. Нажмите «Импорт аудио» и выберите сразу `dialog1.mp3`, `english.mp3` и `long.mp3` - первый файл обрабатывается, остальные в разделе «Очередь» со статусом «Ожидает»
2. Вернитесь на Главную - на карточке задачи «В очереди: 2 файла», `txt_status` на Главной показывает работающую стадию
3. Дождитесь конца первого файла - следующим берётся второй файл, порядок не меняется
4. Дождитесь конца всех файлов - в «Истории» три записи со статусом «Готово» и состоянием протокола
5. Нажмите значок удаления у записи - диалог «Удалить запись?», отметка «Удалить и файл JSON» снята
6. Нажмите «Оставить» - запись на месте
7. Снова откройте диалог и нажмите «Удалить» - запись исчезла из истории, а `adb shell ls /sdcard/Download/Stenokot/` по-прежнему показывает её файл

## Ограничения

- Порядок очереди поменять нельзя
- Диалог удаления не стоит на пути автоматики: импорт и обработка работают без него
