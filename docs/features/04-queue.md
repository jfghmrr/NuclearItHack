# Библиотека и очередь

Одновременно работает одна тяжёлая задача, остальные ждут в порядке поступления. Готовые записи остаются в библиотеке и открываются без повторной обработки.

## Как работает

- Порядок строго по поступлению. Файл копируется сразу, поэтому ждать очереди можно сколько угодно
- Статусы: «Готово», «Обрабатывается», «Ожидает», «Приостановлено», «Ошибка», «Результат сохранён», «Отменено». Статус всегда написан словом и со значком, цвет только дополняет их. Отмена не красится красным
- Записи разложены по дням: «Сегодня», «Вчера», дата. Наверху поиск «Найти запись» и фильтры «Все записи», «Готово», «В работе»
- Работающая задача показывает действие и процент этапа, ждущая «Ожидает · Очередь: {n}», прерванная «Обработка прервалась» и «Продолжить»
- Новый файл во время тяжёлых стадий встаёт в очередь. Если идёт только языковая модель, она останавливается меньше чем за 1 с: новая работа важнее протокола
- Рядом со статусом готовой записи стоит состояние протокола: «Протокол готов», «Протокол частичный», «Протокол отложен», «Протокол остановлен», «Протокол пропущен», «Протокол не создан», «Речи не найдено»
- Удаление требует подтверждения: «Удалить запись?», «Запись и её стенограмма исчезнут из приложения», «Файл JSON в папке Download/Stenokot останется на месте»
- Файл JSON удаляется только по отдельной отметке «Удалить и файл JSON» с предупреждением «Файл JSON будет удалён с устройства, вернуть его нельзя»

## Как проверить

Перед началом: Главная, задач в работе нет.

1. Нажмите «Импорт аудио» и выберите сразу `dialog1.mp3`, `english.mp3` и `long.mp3` - первый обрабатывается, остальные стоят со статусом «Ожидает» и номером в очереди
2. Вернитесь на Главную - `txt_status` показывает работающую стадию
3. Дождитесь конца первого файла - следующим берётся второй, порядок не меняется
4. Дождитесь конца всех файлов - в библиотеке три записи «Готово» с состоянием протокола
5. Выберите фильтр «В работе» - «Ничего не нашлось», кнопка «Сбросить» возвращает список
6. Нажмите значок удаления у записи - «Удалить запись?», отметка «Удалить и файл JSON» снята
7. Нажмите «Оставить» - запись на месте
8. Снова откройте диалог и нажмите «Удалить» - запись исчезла, а `adb shell ls /sdcard/Download/Stenokot/` по-прежнему показывает её файл

## Ограничения

- Порядок очереди поменять нельзя
- Диалог удаления не стоит на пути автоматики: импорт и обработка работают без него
