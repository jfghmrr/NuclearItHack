# Предпроверка файла

Перед загрузкой моделей приложение проверяет файл и показывает, что его ждёт. Подтверждение не требуется: это только сведения. Плохой файл отсеивается здесь, раньше, чем на него уйдут время и память.

## Как работает

- Порядок: имя и размер, запас места, копия файла, пробное чтение копии, снова запас места. Модели в этот момент не загружены
- Пробное чтение проверяет контейнер, наличие звуковой дорожки, параметры звука и наличие декодера. Затем декодер запускается на начале файла: контейнер мог открыться, а данные оказаться мусором
- Обрезанный файл ловится двумя проверками: у MP3 заявленный размер сравнивается с настоящим, а если длительности можно верить, читается участок около конца записи
- Запас места: размер файла, 46 КБ на секунду записи и резерв 64 МиБ
- Если свободной памяти меньше бюджета распознавания, 850 МиБ, появляется предупреждение `LOW_MEMORY`. Обработка не останавливается
- Карточка файла показывает имя, длительность, размер и строку предпроверки: «Запись {длительность}.», оценка времени, «Свободно {место}»
- Оценка времени честная. После записи от 10 секунд на этом устройстве есть замер, и строка звучит как «Ожидаемое время обработки {диапазон}.». Без замера это широкий диапазон с подписью «Примерная оценка времени обработки: {диапазон}.». Без длительности оценки нет совсем
- Оценка показывает время до файла JSON. Протокол в неё не входит

| Что найдено | Код | Куда ведёт |
|---|---|---|
| Не аудио, нет звуковой дорожки, нет декодера | `DECODE_UNSUPPORTED_FORMAT` | Экран ошибки |
| Файл пуст, повреждён или обрезан | `DECODE_CORRUPT` | Экран ошибки |
| Файл не читается, нет доступа | `IMPORT_READ_FAILED`, `IMPORT_NO_PERMISSION` | Экран ошибки |
| Не хватает места | `STORAGE_LOW` | Экран ошибки, копия отвергнутого файла удаляется |

## Как проверить

Перед началом: Главная, приложение только что установлено.

1. Импортируйте `dialog1.mp3` - на карточке файла видны длительность и размер, ниже строка с «Примерная оценка времени обработки:» и «Свободно». Подтверждать ничего не нужно
2. Дождитесь конца обработки и импортируйте запись ещё раз - теперь строка содержит «Ожидаемое время обработки»: оценка опирается на замер этого устройства
3. Импортируйте `broken.mp3` - `txt_status` показывает `FAILED:DECODE_CORRUPT` почти сразу, стадии `RUNNING:ASR` не было
4. Нажмите «Показать все файлы» и выберите `note.txt` - `txt_status` показывает `FAILED:DECODE_UNSUPPORTED_FORMAT`

## Ограничения

- У MP3 без служебного кадра длительность до декодирования известна только по битрейту. Точная считается по числу отсчётов
- Такой MP3 с обрезанным хвостом предпроверка заранее не отличит: он обрабатывается до настоящего конца данных
- Диапазон без замера взят из расчёта, а не из измерений этого устройства
