# Методика и результаты тестирования

Каждое значение подписано средой замера. Чего не мерили, отмечено «не измерено». Результат на компьютере не подменяет результат на Android.

## Методика

Скорость публикуется двумя значениями, никогда просто «RTF». `RTF` - время обработки, делённое на длительность записи.

| Включено | `RTF_core` | `RTF_full` |
|---|---|---|
| Запуск процесса, загрузка моделей, импорт, декодирование, VAD, ASR, диаризация, слияние, запись JSON | Да | Да |
| LLM | Нет | Да |
| Отрисовка интерфейса | Нет | Нет |

Внутри приложения времена стадий пишутся в `metrics.jsonl`, сводка и оба значения в `metadata.json`. Пик памяти берётся из `VmHWM` процесса. Строки прогонов складываются в [artifacts/test-results/results.csv](../artifacts/test-results/results.csv).

Условия сравнения:

- Качество оценивается отдельно по тексту, говорящим и времени. Заполненные паузы входят в эталон и не удаляются
- Тестовые аудио в репозиторий не кладутся, в APK не входят, а модели на них не обучаются
- Значения WER и DER считаются внутренними метриками: методика жюри неизвестна

## Результаты

Сводка на сейчас:

| Показатель | Значение | Условия |
|---|---|---|
| Модульные тесты `:core` | 199 тестов, 0 сбоев | `./gradlew :core:test`, JVM |
| Сумма стадий на записи 3 минуты | около 51,5 с, около 0,29 от длительности записи | Эмулятор, отдельные стадии, таблица ниже |
| Пик памяти стадий до JSON | 803 МБ, на диаризации | То же |
| Пик памяти процесса `:llm` | 776 МБ | Эмулятор, подготовленная стенограмма |
| WER, DER | не измерено | |
| `RTF_core`, `RTF_full` готового APK | не измерено | |
| Стенд проверки жюри | не измерено | |
| Телефон | не измерено | Телефона в работе не было |

Условия замеров на эмуляторе: arm64, 4 ГБ RAM, 4 vCPU, API 36, хост Mac M4. Запуск проверочный, стадии идут отдельно, это не готовый APK. Поэтому числа нельзя считать итогом на стенде проверки.

### Стадии, запись MP3 3 минуты

| Стадия | Время, с | Пик памяти, МБ |
|---|---:|---:|
| Декодирование | 8,3 | не измерено |
| VAD | 1,0 | не измерено |
| Загрузка модели ASR | 2,8 | не измерено |
| ASR | 11,7 | 517 |
| Диаризация | 27,6 | 803 |
| Слияние | 0,02 | не измерено |

После освобождения модели ASR память процесса падала до 257 МБ.

В сумму не входят запуск процесса, копирование файла, определение языка и запись JSON. Поэтому 0,29 - это не `RTF_core`.

### Языковая модель, подготовленная стенограмма

| Показатель | Значение |
|---|---|
| Окон | 11 |
| Статус | `APPLIED` |
| Сгенерировано | 271 токен за 8,4 с, около 32 токенов в секунду |
| Обработка запросов, всего | 57 с |
| Пик памяти процесса `:llm` | 776 МБ |

Стенограмма была заранее подготовленной, а не результатом распознавания в том же прогоне.

`kill -9` процесса `:llm` во время работы оставил основной процесс живым, а работа продолжилась с готовых окон.

## Матрица проверок

Проверки рассчитаны на AVD arm64, API 36, 4 ГБ RAM, 4 vCPU и выполняются на готовом APK. Статус «не проверено» означает, что на готовом APK проверка ещё не проходила.

| № | Проверка | Ожидаемый результат | Статус |
|---|---|---|---|
| R1 | Установка на чистый AVD, импорт сразу, пока копируется языковая модель | Импорт работает, JSON появляется, протокол ждёт копию | не проверено |
| R2 | Файл 60 минут | Память не растёт, падений нет | не проверено |
| R3 | Три файла подряд | Три файла JSON, порядок по поступлению | не проверено |
| R4 | Малый `/data` | `STORAGE_LOW`, сказано, сколько освободить | не проверено |
| R5 | Системный выбор файла и `Download` | Файл выбирается, обработка стартует сама | не проверено |
| R6 | Запуск через `adb shell am start` | Обработка стартует без касаний | не проверено |
| R7 | Файл в `Download/Stenokot/` | Виден без навигации по приложению | не проверено |
| R8 | Английская запись | Определён английский, работает Parakeet | не проверено |
| R9 | Выключенный экран, отказ в уведомлениях | Обработка идёт до конца | не проверено |
| R10 | Плеер без сетевых разрешений | Звук играет, перемотка точна | не проверено |
| R11 | `kill -9`, продолжение с чекпойнта | Работа продолжается с последнего готового среза или окна | не проверено |
| R12 | Авиарежим на всём пути, `aapt2 dump permissions` | Обработка проходит, `INTERNET` нет | не проверено |
| R13 | Повреждённый MP3 | `DECODE_CORRUPT`, сообщение, процесс жив | не проверено |
| R14 | Тишина | `AUDIO_EMPTY`, `{"transcript":[]}`, файл записан | не проверено |
| R15 | Повреждённая языковая модель | JSON готов, статус протокола честный | не проверено |
| R16 | Отказ в сохранении | `EXPORT_FAILED`, автофайл цел, повтор работает | не проверено |
| R17 | Нехватка памяти | `LOW_MEMORY` или `SKIPPED_LOW_MEMORY`, JSON цел | не проверено |
| R18 | Шум, короткие реплики, перебивания | Значения WER и DER записаны | не проверено |
| R19 | Имена, числа, отрицания, термины | Ошибки записаны в [LIMITATIONS.md](LIMITATIONS.md), текст не менялся после ASR | не проверено |
