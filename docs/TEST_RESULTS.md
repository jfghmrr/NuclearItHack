# Методика и результаты тестирования

Каждое значение подписано средой замера. Чего не мерили, отмечено «не измерено». Результат на компьютере не подменяет результат на Android.

Публикуются две скорости, никогда просто «RTF»:

| Включено | `RTF_core` | `RTF_full` |
|---|---|---|
| Запуск, загрузка моделей, импорт, декодирование, VAD, ASR, диаризация, слияние, запись JSON | Да | Да |
| LLM | Нет | Да |
