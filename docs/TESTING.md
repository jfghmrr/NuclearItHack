# Матрица проверок

Проверки выполняются на AVD arm64, API 36, 4 ГБ RAM, 4 vCPU. Результаты записываются в [TEST_RESULTS.md](TEST_RESULTS.md).

| № | Проверка |
|---|---|
| R1 | Установка на чистый AVD, импорт сразу, пока копируется языковая модель |
| R2 | Файл 60 минут: память постоянна, нет падений |
| R3 | Три файла подряд |
| R4 | Малый `/data`, `STORAGE_LOW` |
| R5 | Системный выбор файла и `Download` |
| R6 | Запуск через `adb shell am start` |
| R7 | Файл в `Download/Stenokot/` виден без навигации |
| R8 | Английская запись |
| R9 | Выключенный экран, отказ в уведомлениях |
| R10 | Плеер без сетевых разрешений |
| R11 | `kill -9`, продолжение с чекпойнта |
| R12 | Авиарежим на всём пути, `aapt2 dump permissions` |
| R13 | Повреждённый MP3: `DECODE_CORRUPT`, сообщение, процесс жив |
| R14 | Тишина: `AUDIO_EMPTY`, `{"transcript":[]}`, файл записан |
| R15 | Повреждённая языковая модель: JSON готов, статус честный |
| R16 | Отказ в сохранении: `EXPORT_FAILED`, автофайл цел, повтор работает |
| R17 | Нехватка памяти: JSON цел |
| R18 | Шум, короткие реплики, перебивания |
| R19 | Имена, числа, отрицания, термины |
