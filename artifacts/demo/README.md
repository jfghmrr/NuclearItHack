# Материалы демонстрации

## Видео

[skvor_demo_honor.mp4](skvor_demo_honor.mp4), 110 секунд, 1,2 МБ. Запись экрана Honor NTN-LX1 (Android 13, Snapdragon 662) через `scrcpy`, сборка 1.1.0, 8 ноября 2026, без монтажа и ускорения.

Что видно по порядку:

1. Первый запуск после установки: знакомство из четырёх экранов.
2. Файл `dialog.wav`, 23 секунды, два голоса, второй тише первого, отправлен командой `am start -a android.intent.action.VIEW`.
3. Экран обработки: этапы, проценты и счётчики меняются плавно и только по реальному ходу работы.
4. Стенограмма: два говорящих, переход к реплике в плеере, долгое нажатие открывает правку реплики, лента говорящих.
5. Протокол с темой и ссылкой на реплику.

Тот же файл, исходный WAV и полученный JSON, описан в [docs/TEST_RESULTS.md](../../docs/TEST_RESULTS.md) как запись с тихим вторым собеседником.
